# MobileUI-OS v1.0

A portable agentic UI/UX quality system for premium mobile applications.

## Mission
Combine platform-aware design guidance, UX reasoning, design-system discipline, accessibility, motion, implementation rules, and visual/UX auditing into a reusable skill layer.

## Primary target
React Native + Expo + TypeScript, while keeping the principles framework-independent.

## Quality target
Apple-level UX discipline + Material systemization + modern premium product design + React Native/Expo engineering discipline.

## Core loop
REQUEST → ANALYZE → PLAN → DESIGN → IMPLEMENT → INSPECT → AUDIT → FIX → RE-AUDIT → SHIP

## Source hierarchy
1. Official platform guidance
2. Project design system
3. Product-specific UX decisions
4. Established interaction patterns
5. Inspiration/reference material

Never copy a visual style blindly. Extract the underlying design principle.
